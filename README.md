# 渥康品牌网站

采用苹果官网式留白、产品大图、简洁导航和移动端布局。单页包含全脂与脱脂牛乳粉、产品详情弹窗、产品对比、奶源介绍、日常饮用灵感、品质与包装说明、三步溯源指引以及六项常见问题。

## 本地运行

使用 Node.js 22.13 或更高版本及 pnpm。运行 `pnpm install`、`pnpm dev`；生产构建使用 `pnpm build`。

- 产品文字、配料和营养数值：项目只读资料《直播电商#卖点卡#渥康奶粉袋装#202608(2)(1).pdf》第9、11页；包装和溯源说明参照相关产品页及第16页。

- 产品声明来自提供的2026年8月品牌资料，未独立审核商业资质；以实际产品包装为准。
